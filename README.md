# Sistem Pengelolaan Jadwal Latihan Tenis Meja

## Deskripsi
Sistem Pengelolaan Jadwal Latihan Tenis Meja merupakan aplikasi web sederhana yang dibuat menggunakan Laravel untuk menampilkan informasi dan jadwal kegiatan latihan tenis meja Universitas Jember.

## Fitur
1. **Login:** Pengguna memasukkan username untuk masuk ke aplikasi.
2. **Dashboard:** Menampilkan informasi dan sambutan berdasarkan username.
3. **Pengelolaan Jadwal:** Menampilkan daftar jadwal latihan tenis meja.
4. **Profile:** Menampilkan informasi profil berdasarkan username.
5. **Navigasi:** Memudahkan pengguna berpindah antarhalaman.
